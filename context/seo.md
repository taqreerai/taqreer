# SEO runbook

Status as of 2026-06-18: **Phase 1 (foundation) is shipped and live.** What is left is
mostly *manual* (Search Console, indexing, monitoring) plus the optional Phase 2
content pages. Nothing in code makes the site rank until Google has crawled + indexed
it, and that starts in Search Console.

The full strategy + research lives in `~/.claude/plans/elegant-foraging-hoare.md`.

## Target keywords

- **Brand:** `taqreer` (goal: the site shows as the brand result with description + sitelinks)
- **Arabic head terms:** `تصميم عرض`, `تصميم عروض`, `تصميم عرض تقديمي`,
  `تصميم عرض بالذكاء الاصطناعي`, `تصميم تقرير بالذكاء الاصطناعي`

## What shipped (Phase 1, live on prod)

- **Structured data (JSON-LD)** site-wide: `Organization` + `WebSite` +

- **Robots** (`app/robots.ts`): locale-aware disallows for private app surfaces.

- **OG share image** (`public/og-image.png`, 1200x630) + Google verification hook,
  `theme-color`, web manifest.

## Manual checklist (do these, in order)

### 1. Verify the site in Google Search Console
GSC = how Google reports crawling/indexing + the queries you rank for. Two options:

- **Domain property (preferred):** add `taqreer.ai` as a *Domain* property, then add the
  TXT record GSC gives you to the `taqreer.ai` DNS (Cloudflare). Covers http/https + all
  subdomains, no code.
- **OR URL-prefix property (HTML tag):** add `https://taqreer.ai`, choose the
  "HTML tag" method, copy the `content` token, and set it in prod env:
  ```
  # /root/taqreer/.env  (on the box)
  NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION="<token>"
  ```
  Then **rebuild** (the value is `NEXT_PUBLIC_*`, inlined at build, not just reload):
  ```
  ./deploy.sh --rebuild
  ```
  The `<meta name="google-site-verification">` tag is already wired in
  `app/[lang]/layout.tsx` (renders only when the env var is set).

### 2. Submit the sitemap
In GSC → Sitemaps → add `sitemap.xml` (full URL `https://taqreer.ai/sitemap.xml`).

### 3. Request indexing for the key pages
GSC → URL Inspection → enter `https://taqreer.ai/ar` → "Request indexing". Repeat for
`https://taqreer.ai/en`. This nudges the first crawl instead of waiting.

### 4. Validate the structured data + share card
- Rich Results Test (`https://search.google.com/test/rich-results`) on
  `https://taqreer.ai/ar` → confirm `FAQPage` (+ Organization) valid, no errors.
- Schema validator (`https://validator.schema.org`) for the full graph.
- Share-card: paste `https://taqreer.ai/ar` into the X/LinkedIn/Facebook post-debuggers
  (or just share it) to confirm `og-image.png` renders.

### 5. (Optional) Bing Webmaster Tools
Add the site + submit the same sitemap. Bing also feeds ChatGPT search.

### 6. Monitor (ongoing)
- GSC → Performance: watch impressions/clicks for `taqreer` and the 5 Arabic terms.
- GSC → International Targeting (or the Pages report): confirm the ar/en hreflang pairs
  are recognized, no errors.
- Indexing → Pages: confirm `/ar` + `/en` (and legal pages) are indexed, not excluded.

## Realistic expectations

- **`taqreer` (brand):** achievable once indexed (days to a couple of weeks). The
  Organization/WebSite schema + consistent name + the social `sameAs` links are what
  build the brand entity. **Sitelinks are auto-generated by Google** from site structure
  and traffic, they cannot be forced; distinct indexed pages (Phase 2) make them likelier.
- **Arabic head terms (`تصميم عرض تقديمي` etc.):** these are competitive (Canva, Gamma).
  Phase 1 gives the homepage a real shot at long-tail + brand-adjacent queries, but
  ranking *on the head terms* realistically needs **Phase 2 content pages + backlinks +
  time**. See the plan's "Phase 2 - Hub-and-spoke sub-pages" section.
